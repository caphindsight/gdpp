Grammar: the complete syntax

The formal summary of GD++'s syntax, for reference.

- The page of each topic explains its part.
- For tokens, comments and literals, see `gd++ man syntax`.

# Notation

```
X?          X is optional
X*          any number of X, including none
X | Y       X or Y
( ... )     grouping
'text'      a keyword or punctuation, as written
Ident       an identifier
Int         an integer: '-'? Number
String      a string literal
Block       '{' C++ code '}', up to the matching '}'
```

Whitespace, newlines and comments may appear between any two tokens, except inside `Expr`. See "Values" below.

# Files

```
File        = Code* FileHead? TopItem*
FileHead    = ClassHead | ExternHead | EnumHead | MacroHead | LibraryHead
ClassHead   = Doc? Annotation* 'class_name' Ident ( 'extends' Type )?
ExternHead  = Doc? Annotation* 'extern_name' Ident ( 'extends' Type )?
EnumHead    = Doc? Annotation* 'enum_name' Ident ( 'extends' EnumBase )? EnumEntry*
MacroHead   = ( 'macro_name' | 'template_name' ) Ident '(' MacroParams? ')' Body
LibraryHead = 'macro_library' Body
TopItem     = Class | Extern | Macro | Member
```

- `Code` before the file head is always an error: `decl` and `impl` blocks must be in a class.
- After `class_name` or `extern_name`, every `Member` belongs to that class or extern.
- In a file without either, only enum types are allowed as members at the top level.
- After `enum_name`, only an optional `extends` and enum values follow.
- After `macro_name`, `template_name` or `macro_library`, the rest of the file is the `Body`.

# Classes and externs

```
Class       = Doc? Annotation* 'class' Ident '{' ( 'extends' Type )? Member* '}'
Extern      = Doc? Annotation* 'extern' Ident '{' ( 'extends' Type )? Member* '}'

Member      = Code
            | Annotation* 'ctor' Block
            | Annotation* 'dtor' Block
            | Annotation* 'on' Ident? ( '(' Ident ':' Type ')' )? Block
            | Func
            | Signal
            | Var
            | Enum
            | 'import' Type
            | 'noimport' Type
            | Invoke
```

Externs only allow `Func`, `Signal` and `Var` members, without bodies, initial values or default values.

# Macros and templates

```
Macro       = ( 'macro' | 'template' ) Ident '(' MacroParams? ')' '{' Body '}'
            | 'macro' '{' Body '}'
MacroParams = MacroParam ( ',' MacroParam )* ','?
MacroParam  = Ident ( '=' Default )?
Body        = Lua code (macros) or GD++ code with ${...} holes (templates), with Macro declarations at its top level
Invoke      = Doc? 'invoke' Ident ( '(' ( MacroArg ( ',' MacroArg )* ','? )? ')' | '{' Lua table fields '}' )
            | Doc? 'invoke' '{' Lua code '}'
MacroArg    = ( Ident '=' )? Value
Value       = Number | '-' Number | String | Type | '[' ( Value ( ',' Value )* ','? )? ']'
            | '{' ( MacroArg ( ',' MacroArg )* ','? )? '}' | 'code' Block | Expr
```

- `'macro' '{' Body '}'` is a macro library, only at the top level of a file.
- A `Default` is a Lua expression.
- Positional `MacroArg`s come before named ones. In a dictionary, every `MacroArg` has a key.
- `Ident '='` starts a named `MacroArg` only if another `=` doesn't follow, so `a == b` is a positional `Expr`.
- A `Value` that isn't one of the other forms is an `Expr`: C++ code up to the next `,` or closing bracket.
- In C++ code, `'invoke' Ident '('` or `'invoke' Ident '{'` invokes a macro, if the package has one named `Ident`.
- In C++ code, `'invoke' '{'` is a macro block at the start of the code or of a statement: after `;`, `{` or `}`.
- A macro block's `Lua code` can't declare macros or templates.
- In C++ blocks, `';'` ends the invocation: `Invoke ';'`. In one-line C++ expressions, i.e. initial values and parameters' default values, nothing does.
- See `gd++ man templates` and `gd++ man macros`. Prefer templates whenever they do the job: macros are more powerful, but also more advanced.

# Code blocks

```
Code        = Annotation* ( 'decl' 'impl'? | 'impl' ) Block
```

# Functions

```
Func        = Doc? Annotation* 'func' Ident '(' ParamList? ')' ( '->' Type )? Block?
ParamList   = Param ( ',' Param )* ','?
Param       = Ident ( ':' Type )? ( '=' Default )?
```

# Signals

```
Signal      = Doc? Annotation* 'signal' Ident ( '(' ParamList? ')' )?
```

Signal parameters have no default values.

# Variables and properties

```
Var         = Doc? Annotation* 'var' Ident ( ':' Type )? ( '=' Init | Property )?
Property    = '{' Accessor* '}'
Accessor    = 'decl' Block
            | 'get' Block
            | 'set' '(' Ident ( ':' Type )? ')' Block
```

A property needs exactly one `get`, at most one `set`, and any number of `decl`.

# Enums and constants

```
Enum        = Doc? Annotation* 'enum' Ident ( '=' Int | '{' ( 'extends' EnumBase )? EnumEntry* '}' )
EnumBase    = Ident ( '.' Ident )?
EnumEntry   = Doc? Annotation* Ident ( '=' EnumExpr )? ','?
EnumExpr    = EnumXor ( '|' EnumXor )*
EnumXor     = EnumAnd ( '^' EnumAnd )*
EnumAnd     = EnumSum ( '&' EnumSum )*
EnumSum     = EnumProduct ( ( '+' | '-' ) EnumProduct )*
EnumProduct = EnumUnary ( ( '*' | '/' | '%' ) EnumUnary )*
EnumUnary   = ( '~' | '-' ) EnumUnary | '(' EnumExpr ')' | Int | EnumRef
EnumRef     = Ident ( '.' Ident )*
```

- `enum NAME = Int` is an integer constant, only allowed in a class.
- `enum Name { ... }` is an enum type.
- `EnumBase` is a GD++ enum, or an engine enum, e.g. `Node.ProcessMode` or `Error`.
- `EnumRef` is one of:
  - an earlier value of the enum itself, e.g. `HEARTS`,
  - `Enum.VALUE`, a value of another enum, e.g. `Suit.HEARTS` or `Node.ProcessMode.INHERIT`,
  - `Class.CONSTANT`, e.g. `Node.PROCESS_MODE_INHERIT`.
- `EnumExpr` gives the operators C's precedence.
- A value ends where no operator continues it. So `A = B | C D` holds two values.

# Types

```
Type        = Ident ( '[' Type ( ',' Type )* ']' )?
```

Only `Array`, `Dictionary`, `Async` and `Weak` take type arguments: `Array`, `Async` and `Weak` one, `Dictionary` two.

# Annotations

```
Annotation  = '@' Ident ( '(' ( Arg ( ',' Arg )* ','? )? ')' )?
Arg         = String | Char | '-'? Number | Ident
```

A doc comment can also appear among a declaration's annotations.

# Doc comments

```
Doc         = DocLine+ | DocBlock
DocLine     = '///' text to the end of the line
DocBlock    = '/**' text '*/'
```

# Values

```
Init        = Block | Expr
Default     = Block | Expr
```

- `Expr` is C++ code that starts after `=` and runs to the end of the line. It continues while a `(`, `[` or `{` is open.
- A `Default` also ends at a `,` outside brackets, and before the `)` that closes the parameter list.
- A value that starts with `{` is a `Block`, which returns the value.
- An `Init` that starts with `$` or `%` is a node path, e.g. `$Hud/Score`. See `gd++ man variables`.

# Keywords

```gd++
class  class_name  ctor  decl  dtor  enum  enum_name  extends  extern  extern_name
func  get  impl  import  invoke  macro  macro_library  macro_name  noimport  on  set
signal  template  template_name  var
```

In C++ code, GD++ also reserves:

- `emit`, `rpc`, `is_cancelled`, `string_name`, `is_done`, `claim`, `cancel`, `create`, `destroy`, `queue_destroy`, `as` and `assert`, with its fallbacks `assert_void` and `assert_val`. See `gd++ man rewrites`.
- `This` and `gd`. See `gd++ man code`.
- `invoke`, which invokes macros and starts macro blocks. See `gd++ man macros`.
