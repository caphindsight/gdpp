Tutorials: guides to common goals

The rest of this manual is a reference: each page covers one topic, with every detail. A tutorial is the other way around:

- It takes one goal, e.g. shipping a game or moving work to a thread.
- It walks through all the steps to reach it, across topics.
- It leaves out the details that the goal doesn't need, and links to the reference pages for them.

Facts:

- The tutorials assume that you've read `gd++ man tour`, and have a project with a package that builds.
- They're independent of each other: read the ones whose goals you have, in any order.
- Like the language pages, they describe one syntax version, shown in their titles: in a package, the package's, and elsewhere the latest stable one. See `gd++ man lang`.
