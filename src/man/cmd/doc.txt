gd++ doc: look up godot-cpp and GD++ runtime declarations

# Synopsis

```sh
gd++ doc [PKG] NAME
gd++ doc [PKG] NAME.MEMBER
gd++ doc [PKG] [-i]
gd++ doc [PKG] --notifications
```

# Description

Shows the C++ declaration of a name in godot-cpp, like `go doc`: the class, function, alias or enum, its comments, the header to include, and its public members, then the members it inherits, grouped by base class. It's the reference for godot-cpp's own helpers, e.g. `TypedArray`, `Ref`, `memnew` or `UtilityFunctions`, which Godot's help doesn't describe. Godot's classes are declared there too, e.g. `Node3D`. For what they do, see Godot's help, which the output points to. It also shows what the GD++ runtime declares, e.g. `Ext`, `Weak`, `Async` or `create`: the helpers in namespace `gdpp` of the package's runtime header. See `gd++ man runtime`.

The names come from the bindings of a package, generated from its API spec, and from the runtime header of its syntax version, so you see exactly what your code can use. Where both declare a name, godot-cpp's is shown. PKG is a path in that package. Without it, `gd++ doc` uses the package that contains the current directory. The first run in a package may take a while, since it generates the bindings. See `gd++ man build-cache`.

The output goes through the pager when it doesn't fit the terminal, and is highlighted as C++ on terminals. See `gd++ man cli`.

# Arguments and options

PKG
  A path in the package whose bindings to use. Default: the current directory.

NAME
  The name to show, e.g. `TypedArray`, `Node3D`, `Vector3` or `memnew`. Names are case sensitive.

NAME.MEMBER
  Show only the members called MEMBER of NAME, with their comments, e.g. `Array.push_back`. All overloads are shown. If NAME doesn't declare the member, its base classes are searched, nearest first, through aliases too.

-i, --index
  List every type that godot-cpp and the GD++ runtime declare: its kind, e.g. class, struct, enum, template class or alias, its name, and its base class or what it aliases. This is the default without a name. Can't be used with a name.

--notifications
  List the notifications of each Godot class in the package's API spec, as `on` blocks name them, e.g. `ready` for `on ready { ... }`. Each class is followed by its own notifications, without those of its bases, one per line, indented by the tab width. Can't be used with a name or `--index`. See `gd++ man notifications`.

# Output

For a class:

```cpp
#include <godot_cpp/variant/typed_array.hpp> // From godot-cpp.

template <typename T>
class TypedArray : public Array {
  TypedArray();
  void assign(const Array &p_array);
  ...

  // Inherited from Array:
  void push_back(const Variant &p_value);
  ...

  // Inherited from Object:
  ...
};
```

The output reads like a C++ header. First comes the `#include` line that you need to use the name, with a comment that says where the header comes from: `// From godot-cpp.` for godot-cpp's own headers, `// From the Godot API.` for those generated from the API spec, and `// From the GD++ runtime.` for the runtime header. Then come its declarations, each with the comments right before it in the header, and its public members in braces, indented by the tab width (see `-T` in `gd++ man cli`). An alias is followed by the type it aliases, in full. The members of each base class come last in the braces, in order. For classes generated from the API spec, a last line says "See Godot's help for a description of NAME.".

With NAME.MEMBER, the `#include` line of the class that declares the member comes first, then the member.

The index lists one type per line:

```cpp
class Array: Object
alias CharString = CharStringT<char>
template class TypedArray: Array
```

The list of notifications has each class, then its notifications, one per line, both sorted by name:

```
CanvasItem:
  draw
  enter_canvas
  ...
Object:
  extension_reloaded
  postinitialize
  predelete
```

# Examples

```sh
gd++ doc TypedArray                  # a godot-cpp helper, and its members
gd++ doc Array.push_back             # one member
gd++ doc Node3D.rotate_y             # a method of a Godot class
gd++ doc UtilityFunctions.print      # what gd::print is
gd++ doc Ext                         # a GD++ runtime helper
gd++ doc tools Ref                   # with the bindings of the package in res://tools
gd++ doc                             # all types
gd++ doc | grep Packed               # all packed array types
gd++ doc --notifications             # the notifications of all classes
```

# Errors

- "There is no name NAME in godot-cpp or the GD++ runtime. Similar names: A, B." The name doesn't exist. The names that contain it, ignoring case, are listed if there are at most 10.
- "Name NAME has no public member MEMBER."
- "Invalid arguments: --notifications cannot be used with a name." `--notifications` lists all classes.
- "Path ... is not contained in a GD++ package, run this in one or pass one, e.g. `gd++ doc PKG NAME`."
- "Failed to find the header ..., run `gd++ clean` to fix this." The build cache is out of date.
