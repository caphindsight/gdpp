gd++ rm: remove dependencies, packages, classes or hidden directories

# Synopsis

```sh
gd++ rm [--bind NAME... | --bind-all | --bind-checked-in | --bind-ephemeral | --bind-unused]
        [--spec NAME... | --spec-all | --spec-checked-in | --spec-ephemeral | --spec-unused]
        [--engine NAME... | --engine-all | --engine-checked-in | --engine-ephemeral | --engine-unused]
gd++ rm --dep-all | --dep-checked-in | --dep-ephemeral | --dep-unused
gd++ rm (--pkg PATH... | --pkg-all) [--dir]
gd++ rm PATH (--class NAME... | --class-all)
gd++ rm PATH (--hide DIR... | --hide-all)
```

# Description

Removes one of four things per run:

- dependencies from the project's caches,
- packages from the project,
- C++ classes from a package,
- hidden directories from a package.

Facts:

- Every removal is confirmed first.
- `gd++` asks all its questions before it removes anything. So answering no changes nothing.
- After removing dependencies or packages, it deletes the cache directories left empty.
- See `gd++ man cli` for `-f` and `-n`.

# Removing dependencies

--bind NAME...
  Remove these Godot C++ bindings, from both caches. Each one is confirmed on its own.

--bind-all
  Remove all Godot C++ bindings, checked in and ephemeral. Confirmed once.

--bind-checked-in
  Remove all checked in Godot C++ bindings, from `res://_gd++`.

--bind-ephemeral
  Remove all ephemeral Godot C++ bindings, from `res://.gd++cache`.

--bind-unused
  Remove all Godot C++ bindings that no package of the project uses, from both caches. Confirmed once.

--spec..., --engine...
  The same, for Godot API specs and Godot engines. Removing an engine also removes its copy that `gd++ test` compiled, in `res://.gd++cache/godot`.

--dep-all, --dep-checked-in, --dep-ephemeral, --dep-unused
  The same, for all dependencies of all kinds at once. Confirmed once. Not with the options above.

Rules:

- One option per kind, e.g. not `--spec` with `--spec-all`.
- Kinds combine, e.g. `gd++ rm --bind-ephemeral --spec 4.3-stable`.
- Every named dependency must exist. `gd++` checks them all before it asks anything.

Facts:

- Removing a dependency that a package uses breaks the package's next build, until you fetch it again.
- It doesn't break the package's build cache, which has its own copy.
- `gd++ ls --deps` shows which dependencies are unused. `--dep-unused` removes only those.

# Removing packages

--pkg PATH...
  Remove the packages at these paths. Each path must be a package root in this project.

--pkg-all
  Remove all packages of the project.

--dir
  Delete the package directories with everything inside, including your source files. Without it, only GD++'s files are deleted. It can't delete the project root. The prompt warns about it in bold, blinking red.

Without `--dir`, removing a package deletes:

- its `.gd++pkg`,
- its build cache,
- its libraries and `.gdextension` files, like `gd++ clean --bin`,
- its block in `.gitignore`.

Facts:

- Your GD++ and C++ files stay. The directory is no longer a package, and its files belong to the enclosing package, if any.
- Nested packages are removed before their parents.

# Removing classes

```sh
gd++ rm PATH --class NAME...
gd++ rm PATH --class-all
```

- Removes C++ classes from the `.gd++pkg` of the package at PATH. The package no longer registers them with Godot.
- Their files stay.
- GD++ classes can't be removed this way: delete them from their GD++ files instead.

See `gd++ man cpp-classes`.

--class NAME...
  Remove these classes. Each one is confirmed on its own.

--class-all
  Remove all C++ classes of the package. Confirmed once. If there are none, it says "Nothing to remove.".

# Removing hidden directories

```sh
gd++ rm PATH --hide DIR...
gd++ rm PATH --hide-all
```

- Removes directories from the `hide` list in the `.gd++pkg` of the package at PATH, so Godot sees them again.
- Deletes their `.gdignore` files.

See `hide` in `gd++ man packages`.

--hide DIR...
  Stop hiding these directories. Each DIR is relative to the package root, e.g. `src`. Each one is confirmed on its own.

--hide-all
  Stop hiding all directories of the package. Confirmed once. If there are none, it says "Nothing to remove.".

# Examples

```sh
gd++ rm --spec 4.3-stable                  # an old spec
gd++ rm --bind-ephemeral --spec-ephemeral  # everything that `fetch --missing` can download again
gd++ rm --dep-unused                       # what no package uses, e.g. after an upgrade
gd++ rm --dep-all -f                       # all dependencies, without asking
gd++ rm --pkg tools                        # make res://tools a plain directory again
gd++ rm --pkg old_stuff --dir              # delete res://old_stuff entirely
gd++ rm . --class Spinner                  # stop registering a C++ class
gd++ rm . --hide src                       # show res://src in Godot again
```

# Errors

- "Invalid arguments: dependencies, packages, classes and hidden directories cannot be removed in the same run."
- "Invalid arguments: the syntax for removing a package is `gd++ rm --pkg PATH`." A path was given without `--class` or `--hide`.
- "The Godot API spec NAME is not in the project cache."
- "There is no GD++ package at PATH."
- "The package PATH is not in this project."
- "Class NAME is declared in FILE, so it can only be changed there." It's a GD++ class.
- "Directory DIR is not hidden in PATH."
