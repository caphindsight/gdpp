gd++ clean: delete build caches

# Synopsis

```sh
gd++ clean [PATH...] [--bin]
```

# Description

- Deletes the build cache, `.gd++build`, of the package that contains each PATH.
- The next build starts from scratch: it copies the dependencies again, and compiles godot-cpp and all code again.
- With `--bin`, also deletes the package's built files: every library and `.gdextension` file in its root.
- Always safe: build caches only hold generated files.
- `gd++` checks every path before it deletes anything.
- With nothing to delete, it says "Nothing to clean.".
- Writes a missing `.gdignore` file into each package's hidden directories. See `hide` in `gd++ man packages`.

Clean when builds fail in ways that make no sense, e.g. after a crash during a build, or when `gd++` tells you to. See `gd++ man build-cache`.

# Options

PATH...
  Clean the packages that contain these paths. Default: `...`.
  - `DIR/...` cleans every package in `DIR`, e.g. `res://...` the whole project, and `...` or `./...` the current directory.

--bin
  Also delete all libraries and `.gdextension` files in the package roots, whatever their names: `lib*.dll`, `lib*.so`, `lib*.dylib`, `*.gdextension` and `*.gdextension.uid`.
  - So it also deletes the leftovers of a renamed package.
  - After this, Godot can't load the package until you build it again.

# Examples

```sh
gd++ clean                    # every package in the current directory
gd++ clean gameplay tools     # two packages
gd++ clean res://... --bin    # everything that builds made, in all packages
```

# See also

`gd++ man build-cache`, `gd++ man build` (for `gd++ build --clean`), `gd++ man fix`.
